# ruze · demo 0.1

Первая веб-демоверсия мессенджера: чёрный фон, лаймовые акценты, личные беседы и пространства с категориями и текстовыми каналами. HTML, CSS и JavaScript без зависимостей и сборки.

## Запуск

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Выберите беседу или пространство, создайте канал кнопкой «+», отправьте сообщение. Enter отправляет, Shift + Enter добавляет строку. На телефоне стрелка возвращает к списку бесед; вкладки «Люди» нет.

## Данные и ограничения

Это **локальная демонстрация**, без сервера, регистрации, доставки сообщений и синхронизации. Исходные сообщения помечены «ПРИМЕР». Отправленные сообщения не получают автоматических ответов и сохраняются только в localStorage этого браузера (ключ `ruze-demo-v1`). При недоступном хранилище показывается уведомление; сессия продолжает работать в памяти. Очистка данных сайта удаляет локальные сообщения и каналы. Не используйте демо для хранения важных или конфиденциальных данных.

## GitHub Pages

После слияния в `main` workflow `.github/workflows/pages.yml` публикует только четыре публичных файла. В настройках репозитория **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. При необходимости запустите workflow вручную. Ожидаемый адрес: https://ruze-developer.github.io/ruze-ms/ . Публикация требует включённого GitHub Pages; создание PR само по себе сайт не публикует.

## Проверка

Синтаксис: `node --check app.js`. Проверенные браузерные сценарии и размеры экранов описаны в `TESTING.md`.
