LISTO / ДОКУМЕНТЫ

политика конфиденциальности.

дата редакции: 29 октября 2026 года. этот документ описывает предполагаемую обработку данных на listo. перед запуском платежей необходимо указать юридическое имя оператора и его контактный адрес.

1. какие данные используются

при регистрации и использовании сервиса могут обрабатываться никнейм, технический идентификатор аккаунта, сведения об авторизации, опубликованные объявления и их содержание. при входе через Google могут поступать данные профиля, разрешённые пользователем. пароль обрабатывается сервисом авторизации Supabase; listo не должен хранить его в открытом виде.

2. для чего

данные необходимы для входа, размещения объявлений, обеспечения безопасности, работы каталога и рассмотрения обращений. при подключении платежей перечень данных и получателей будет дополнен.

3. кто обрабатывает

для авторизации и базы данных используется Supabase, для размещения сайта могут использоваться Vercel и GitHub Pages. технические сведения могут обрабатываться этими поставщиками в соответствии с их условиями. вход через Google регулируется также политикой Google.

4. хранение и защита

данные хранятся столько, сколько требуется для работы аккаунта и исполнения законных обязанностей. применяются разграничение доступа и правила доступа к базе данных. абсолютная безопасность не гарантируется.

5. ваши права

можно запросить сведения о своих данных, исправление или удаление в пределах применимого законодательства. канал связи для таких запросов будет опубликован до коммерческого запуска.

6. обновления

при изменении функциональности, платежей или правил обработки эта политика будет обновляться.

важно: документы требуют проверки и указания данных оператора до коммерческого запуска.
