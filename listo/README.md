# listo v5

Статический прототип: единый дизайн главной и категорий Minecraft / Telegram / Roblox.

Откройте `index.html` в браузере. Категории открываются по адресам вида `minecraft.html?keys`. Настройки темы — `settings.html`. Тёмная тема по умолчанию; выбор сохраняется в localStorage.

Товары не подставлены: интеграция с базой данных пока не реализована.
