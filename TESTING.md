# Проверка демоверсии

Проверено в Chromium через Playwright, запуск через локальный HTTP-сервер.

- Создание текстового канала в выбранном пространстве и категории; нормализация пробелов и проверка повторного имени.
- Отправка сообщений кнопкой и Enter; переключение личных бесед, каналов и пространств.
- Сохранение сообщений, каналов и выбранного чата после перезагрузки.
- Черновики при переключении между беседами в пределах сессии.
- Строка с HTML отображается текстом, DOM-элементы из неё не создаются.
- Повреждённый JSON в localStorage: безопасное открытие новой демосессии с уведомлением.
- Ошибка записи в localStorage: уведомление и продолжение работы в памяти.
- Экраны 320, 390, 768 и 1440 пикселей: нет горизонтального переполнения страницы; на телефоне список и чат переключаются, кнопка возврата работает, вкладки «Люди» нет.
- Визуальная проверка скриншотов настольной и мобильной версии.
- Ошибок JavaScript в браузере нет; `node --check app.js` проходит.

GitHub Pages deployment выполняется после слияния в `main` и выбора GitHub Actions в настройках Pages. Реальная серверная переписка и доставка сообщений не реализованы и не имитируются.
